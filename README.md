# CV Storytelling - JavaScript

Presentación de mi trayectoria profesional utilizando **JavaScript**. Este proyecto transforma el currículum tradicional en una experiencia narrativa (storytelling) para resaltar hitos y habilidades de manera dinámica.

## Características
- **Narrativa Interactiva:** Presentación de experiencia paso a paso.
- **Diseño Responsivo:** Optimizado para diferentes dispositivos.
- **Ligero:** Construido principalmente con JavaScript vanilla para un rendimiento rápido.

## Tecnologías
- **HTML5** & **CSS3**
- **JavaScript (ES6+)**
